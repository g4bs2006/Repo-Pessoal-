## Template dos 4 Comentários de Seção (para clientes novos)

Ao criar uma task de novo cliente, criar estes 4 comentários na ordem abaixo:

```
1. "Mapeamento Inicial ( O \"manual de instruções\" da clínica. É onde o dev entende como o negócio funciona e quais são as particularidades.)"

2. "Sucesso (Feedback + Cases) - Prints de elogios, depoimentos e os resultados positivos que a contact trouxe."

3. "Demandas (Mudanças + Bugs)-  O que precisa de ação. O histórico do que foi pedido de novo e o que deu erro especificamente para esse cliente."

4. "Dados (Tech + Contatos) - A parte técnica e burocrática. Links de documentação, chaves de API e quem é o contato técnico lá dentro"
```
